## October 21, 2026: plugin v0.3.0, helper mode logs its helpers; `helper_report` prices them against the rewrite

$0, no model request. User request: "make it track automatically and we can see later how much it actually saves". Branch `claude/helper-log`, cut from `main` (`08fbed4`, PR #122 merged).

- **New: the helper-mode log.** It goes to `helper-log.jsonl` in the plugin's data directory. A line holds ids, the model and effort and the transcript's path, never the brief or the reply.
  - `hooks/helper.sh` writes one `note` line per prompt that got the note.
  - New `hooks/helper-log.sh`, run by PostToolUse (matcher `Agent`) and SubagentStop, writes a `launch` line per `modelpilot:helper-*` launch and a `finish` line per finish. A launch from inside a helper names that helper as its `caller`. The hook reads each field's first occurrence, because `tool_response` and `background_tasks` repeat some keys. Other agents are skipped.
- **New: `modelpilot/helper_report.py`** ($0, offline). It reads the log and Claude Code's transcripts and prices each top-level helper at API rates:
  - measured: the helper's requests, nested helpers included; its startup (each helper's first request without its output); the session's side (the output of the request that wrote the brief, plus the turn after the helper's task notification); the session's prompt at the launch;
  - estimated: the rewrite `/model` to the helper's setting would have written at that prompt (`switch_quote.quote`);
  - `est_saving_usd` = rewrite − startup − session side. Re-reads the session already held make it too high. The new model reading the whole conversation and the rewrite on switching back make it too low. Quality isn't measured. A missing transcript or unpriceable usage stays None, and the totals cover priced rows only.
- **Why no `/model` run is needed first:** the cache is keyed by model, and M0 showed a model switch writes a new prefix. So the rewrite follows from the conversation's size, which the log's launch request measures. Whether a helper matches `/model`'s quality needs paired runs. Nothing here does that.
- **Found by the scratch probe** (2.1.284, fixture, not saved):
  - the Agent tool starts the helper in the background (`async_launched`), so PostToolUse fires at the launch;
  - `resolvedModel` is `claude-opus-5-5[1m]`;
  - SubagentStop carries `agent_transcript_path`;
  - helper transcripts are `<session>/subagents/agent-<id>.jsonl`.

  The fixture replays its scripted Agent call to each helper, so each helper launched another. A helper has the Agent tool, and the log and report count such nested helpers.
- **Changed: `plugin_check`.** Each case keeps the log's events. `findings['helper']` gains `log` (`log_summary`) and `log_without_mode`. Results: `runs/plugin-check-2.1.284-20261021.json`, `runs/plugin-check-2.1.305-20261021.json`. On both clients:
  - one note line, one session launch (helper-high, opus, session at medium), a finish for every launch (3, 2 of them nested);
  - nothing logged without helper mode;
  - the v0.2.0 findings unchanged; validation passes.
- **Not tested:** a live session; an interactive one; whether real helpers start helpers of their own; Windows.
