## October 23, 2026: helper mode against `/model`, three sequence arms for one paired run (built, not run)

$0, no model request. User request: "can we run tests and see if the delegation is cheaper and without sacrificing quality ... I want to just run one big test with a sub token". Branch `claude/helper-vs-switch`, cut from `main` (`b8313b2`, PR #123 merged).

- **Why sequences:** in a single-prompt task, `/model` writes nothing extra (there is no conversation yet), so a helper can only add cost there. The saving is the rewrite of the conversation, so the test runs in long sessions (`long_session`, the 8 tuning sequences of 3 to 5 tasks).
- **New arms** (`bench.ARMS`, sequence shape only; `run_bench` and the CLI refuse them elsewhere): `low-concise-stay`, `low-concise-switch-opus`, `low-concise-helper-opus`.
  - Each is Sonnet 5.5 low with the concise prompt, the Agent tool, and `--plugin-dir` set to a copy of `plugin/` in the trial directory, without `settings.json`. That file sets the lean agent, whose model would override the arm's.
  - The three have the same prefix until each sequence's last task. There the first stays, the second resumes with `--model claude-opus-5-5 --effort medium` (what `/model` and `/effort` do), and the third gets helper mode saved as `opus medium` (the file `/modelpilot:helper opus medium` writes). The prompt itself is unchanged.
- **Changed checks:** `effort_check` takes `{model: effort}`: each request at its model's effort, and no other model. For the helper arm, `prompt_check` counts only the session model's requests, because a helper has its own prompt.
- **Changed report:** `long_session.turns` records each turn's models. `report` drops ineligible trials (counted per arm). It adds `last_task` per arm (passes, mean dollars, the models the last turns used) and per pair (paired cost and pass-rate differences on the last tasks alone).
- **$0 probe** (scratch, not saved): pinned 2.1.284 against the fixture with the bench's flags (`--setting-sources ''`, the plugin copy). The session ran on Sonnet 5.5 low with the concise prompt and the helper on Opus 5.5 medium. The session's system prompt was the same with helper mode on and off, and the note came only with helper mode on.
- **Run script:** `runs/helper-vs-switch-20261023.sh plan|a|b|report`, on the subscription. At the user's request it is split into two equal halves, one token each, to run side by side overnight. Each half has 4 sequences (14 of the 28 tasks) × 3 arms × 3 trials = 36 sessions, and one of the two sequences whose last task Sonnet often misses: `a` is `networkx-a` (`nx-ismags-monomorphism`), `tomli`, `cachetools-a`, `networkx-b`; `b` is `parse` (`parse-decimal-grouping`), `more-itertools-a`, `more-itertools-b`, `cachetools-b`. Each half reads its own run directory from the bench's output; `report` pairs both. Plan-only check of both halves ($0): 14 references graded and 36 trials planned each.
- **Changed: `bench` picks a run directory nobody has taken.** Two runs that started in the same second would have shared `runs/bench-<time>`; the second now waits for the next free second.
- **Expected size:** the forecast (`long-session-forecast-20261011.json`) puts low concise at about 32k tokens at a sequence's end, so about 24k before the last task. That makes a `/model` rewrite about $0.12 on Opus 5.5 (5m). Real sessions are often longer, and the saving grows with the conversation while the helper's overhead doesn't.
- **Not tested:** a live run; whether Sonnet at low effort follows the note; the helper's quality.
- **Tests:** new in `tests/test_long_session.py`: a real-client sequence for the switch and helper arms (models, efforts and the note per turn, the Agent tool, both checks applied, a single-shape run refused) and the report's last-task figures. All 1,112 offline tests pass on Python 3.12 with the pinned 2.1.284 client first on PATH, no skips (`runs/helper-vs-switch-regression-py312.log`).
