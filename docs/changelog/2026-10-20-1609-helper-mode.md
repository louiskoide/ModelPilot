## October 20, 2026: plugin v0.2.0, helper mode (another model without the cache rewrite); effort alone stays on `/effort`

$0, no model request. User request: "begin building the cheap model and effort switching from delegation and the other thing from the effort". This follows the October 19 conversation: delegation for a model change, and the free effort change. Branch `claude/helper-mode`, cut from `main` (`9e1786d`, PR #121 merged).

- **New: helper mode in `plugin/`**, opt-in and off by default. The user sets it, so it isn't routing. Delegation stays off in the benchmark arms.
  - `commands/helper.md`: `/modelpilot:helper MODEL [EFFORT] | off | status`, with sonnet, opus or haiku and low to max (default medium). `hooks/helper.sh` (UserPromptSubmit) handles it and blocks the prompt, so the command sends no request. It saves the setting per session, under `CLAUDE_PLUGIN_DATA`. The command's body only says the hook didn't run.
  - While a setting is saved, each prompt gets a note of about 140 tokens. It asks the session to call the Agent tool once with `modelpilot:helper-<effort>` and the chosen model, write a self-contained brief and relay the reply.
  - `agents/helper-{low,medium,high,xhigh,max}.md` set the effort. They have no model of their own, because the Agent call's `model` sets it. On 2.1.284 the Agent tool takes `model` (sonnet, opus, haiku, fable) but not `effort`, and a plugin agent's `effort` does apply to a helper (scratch probe, then `plugin_helper` below). Each agent has a short prompt that asks for the work to be checked and a short reply.
  - **Found by the check:** the client also runs UserPromptSubmit for `<task-notification>` prompts, when a helper finishes. The first version added the note to those too, which could have handed a finished helper's result to another helper. The hook now skips them.
- **The effort part needs no new mechanism.** `plugin_check`'s new `effort_resume` case resumes a low-effort session at `--effort high`. The client kept the earlier messages unchanged (cache markers aside) and kept its first note at low. It added a message carrying `effort: high` at the new turn, and changed the top-level effort. The October 1 live probe found that this shape keeps the cache: an effort message at a turn start, and a top-level change with the client's effort message present. `switch_quote` already prices an effort-only change as no rewrite. So the plugin points effort-only changes at `/effort`. Not checked: the interactive `/effort` path, and the live cache on the real client.
- **Changed: `switch_quote`.** A delegated helper now also pays its own base, the system prompt and tool definitions: `LIMITS['helper_base_tokens']` 7,500. That was measured on the fixture as about 30,000 characters on 2.1.284, at about 4 characters a token. `max_helper_tokens` still caps the brief and re-reads only. Sonnet 5.5 low to Opus 5.5 high at 120,000 prefix tokens: rewrite $0.576, helper $0.143 (was $0.105), still "delegate".
- **Changed: `plugin_check`.** New case `plugin_helper`: helper mode is saved as opus high, and the fixture makes the Agent call the note asks for. New check `effort_resume`. `summarize` counts the helper-mode note. `capture` takes tools, plugin data files and a script.
- **Results** (the evidence row): `runs/plugin-check-2.1.284-20261020.json`, `runs/plugin-check-2.1.305-20261020.json` (2.1.305 is the user's installed client). They agree:
  - the helper ran on Opus 5.5 at high while the session stayed on Sonnet 5.5 medium;
  - the note arrived once in the session's requests, never in the helper's, and never without helper mode;
  - on resume the efforts were low then high, the message efforts `[[1, "low"], [4, "high"]]`, and the prefix was kept;
  - the v0.1.0 findings are unchanged;
  - `claude plugin validate --strict` passes for the plugin and the marketplace.
- **Not tested:**
  - a live session. Cost and quality against `/model` are unmeasured, and the fixture scripts the Agent call, so whether the session's model follows the note isn't shown;
  - the interactive slash command (in `-p` the hook sees `/modelpilot:helper opus high` raw, blocks it, and no request goes out);
  - resume and compaction with helper mode on;
  - Windows.
- **Tests:** new in `tests/test_plugin.py`: the helper files, the hook's set/status/off/usage/per-session/task-notification behaviour, and the two real-client findings. All 1,106 offline tests pass on Python 3.12 with the pinned 2.1.284 client first on PATH, no skips (`runs/helper-mode-regression-py312.log`; the changelog entry was written while it ran, and `tests.test_changelog` and `tests.test_claude_md` pass after it).
