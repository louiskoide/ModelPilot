## October 15, 2026 (overnight cloud run): a client-version compatibility matrix; from 2.1.289 the client starts in auto permission mode

$0, branch `claude/client-matrix` (overnight item 9, stacked on `claude/doctor`). New `modelpilot/client_matrix.py` and `tests/test_client_matrix.py`. This is a report only: **the pin stays 2.1.284**. The table is in `docs/m1-results.md`, "Client compatibility matrix (October 15)".

- **Versions:** 2.1.284, 2.1.289, and the newest three on npm (2.1.299, 2.1.300, 2.1.301), each installed into the ignored `work/claude-client-<version>`. Each was driven only against loopback fixtures through the proxy, with an empty `HOME`, a fake key, no inherited environment and no retries.
- **Unchanged across all five:**
  - the request shape against `claude-2.1.284-shape.json`, including the trailing system message;
  - 5m breakpoints with an API key;
  - the proxy recognising `/compact`;
  - the hook payloads' fields, where the hook fired;
  - proxy tokens equal to the client's;
  - a single send on a 429 or 529;
  - the hidden re-send without streaming after a cut or idle stream.
- **Changed from 2.1.289:**
  - **The client starts in `permissionMode: auto`.** Before one Bash call it sent 10 non-streamed requests to `claude-sonnet-5`, which the fixture can't answer, so the command was refused. As a result `PostToolUseFailure` never fired. `--permission-mode default` restores 2.1.284's behaviour; bench and `governed_session` don't pass it.
  - **A 400 is sent a second time**, the known "retries refused requests".
  - Four betas added. From 2.1.299, `mid-conversation-system-2026-04-07` is dropped.
- **An upgrade** (a decision for the user) would need `--permission-mode` set explicitly, accounting for the classifier's side requests, the 400 retry handled in the bench's accounting, and a new shape fixture. The costs are in the overnight report.
- **Tests:** all 929 offline tests pass on Python 3.12 with the pinned 2.1.284 client, no skips (`runs/cloud-overnight-client-matrix-regression-py312.log`). `tests/test_client_matrix.py` (8 tests) covers the helpers on fixtures, plus three probes on the pinned client only, which skip without it. It also passes on Python 3.10.20.
