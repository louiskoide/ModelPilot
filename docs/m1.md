# M1: dry-run proxy and overnight validation

M1 now has a loopback-only Messages API proxy, metadata logging, an accounting observer and cost-only switch scenarios. No policy changes requests. The eight-hour synthetic soak completed successfully with 11,496 verified requests and zero failures; see [results](m1-results.md). Basic Claude Code text and Read-tool integration now passes with matching client/proxy costs; cancellation and broader compatibility remain unverified.

## Implemented behavior

- Forward JSON request bytes, cache markers, model/effort settings, authentication and API headers unchanged, except HTTP hop-by-hop/framing headers and Accept-Encoding, which is set to identity for usage accounting.
- Support `/v1/messages` and `/v1/messages/count_tokens`, including query parameters. Client request uploads need either exactly one Content-Length or a strictly parsed `Transfer-Encoding: chunked` body (Jev's proxy uploads chunked). The body is forwarded with a Content-Length, and the maximum body size is 32 MiB. The proxy refuses with 400, and never forwards, an upload that carries both framings, any encoding other than plain `chunked`, a malformed chunk size or framing, or an oversized body. `GET /v1/models` (with any query string) passes through for model-catalog discovery. It is logged as a `kind: models` row with no cost, and every other GET path except `/health` returns 404. Messages rows carry `kind: messages` and `tool_count`. The CLI accepts `--upstream` for a loopback test origin.
- Stream upstream response bytes incrementally to clients, preserve status codes and retry headers, and never retry a request automatically. Upstream chunk framing is decoded; clients receive close-delimited HTTP/1.0 responses.
- Observe SSE usage without changing SSE bytes. Cumulative output counters replace prior counts. Incomplete, malformed, compressed or unpriced responses retain an unknown cost rather than zero.
- Log request hashes, known model names, numeric token totals, timing, errors by type and hypothetical scenarios. No prompts, completions, authentication values or raw error bodies enter proxy logs. Log files are created owner-readable/writable.
- Compare 1/5/20-step cost scenarios assuming source warm, target cold, fixed context, fixed token output and a 5-minute TTL. These are sensitivity calculations, not learned forecasts or quality judgments. Every decision remains `hold` with `applied: false`.

Cost estimates use configured standard/global model rates. Unknown model aliases/fallbacks, nonstandard pricing and absent cache-write TTL splits are not guessed. Provider tool surcharges and billing reconciliation are outside this first version. Do not use its estimates as a hard spending cap.

## Validation

22 unit/integration tests passed before launch. Integration tests cover byte-preserving request and response forwarding, authentication/beta headers, cumulative SSE accounting, incremental arrival, HTTP errors without retry, stream errors, and absence of sensitive fixture strings in logs.

A 10.8-second concurrent smoke test verified 372 requests with zero failures. The overnight soak runs four concurrent synthetic requests per batch at ten-second intervals for eight hours: JSON success, streaming success, HTTP rate-limit error and streaming error. For each response it checks bytes/status, request hashes, usage/cost availability, no applied routing and no fixture credentials/prompts in logs. Status includes peak RSS and active thread count for subsequent review.

The fake upstream binds to loopback; the soak cannot select an external upstream, and its launcher removes ANTHROPIC_* environment variables. Actual API cost of the soak is zero. Numeric cost fields inside synthetic observations are fixture-based estimates, not charges.

## Manual commands

Run all checks:

```sh
python3 -m unittest discover -s tests -v
```

Start a fresh synthetic run:

```sh
caffeinate -i python3 -m modelpilot.soak --hours 8 --out runs/m1-new-soak
```

Start the real upstream proxy only when ready for Claude Code integration:

```sh
python3 -m modelpilot.proxy --port 8787 --config configs/m0.json --log runs/proxy/observations.jsonl
```

Point an API-key-based client at `http://127.0.0.1:8787` using its base-URL configuration. The client supplies authentication; the proxy does not load a saved key. Real forwarded calls remain billable even though routing decisions are dry-run. No existing Claude Code settings have been changed.

Before considering M1 complete, verify actual Claude Code streaming, tool calls, cancellation and headers through this proxy. Subscription OAuth, cloud-provider adapters, connection pooling, long-running streams beyond the 120-second inactivity timeout and server-side fallback accounting are not certified by synthetic tests.

Streaming usage semantics: [Anthropic streaming documentation](https://platform.claude.com/docs/en/build-with-claude/streaming).

## Real Claude Code integration check

A project-local Claude Code client is installed under `work/claude-client` (ignored by Git). Run:

```sh
python3 -m modelpilot.claude_check --live
```

This starts an ephemeral proxy and runs two small Sonnet 4.6 tasks with no tools or the Read tool only. It uses ANTHROPIC_API_KEY from the invoking Terminal, or asks for a hidden key when missing. Each task has a $0.50 client stop threshold, not a guaranteed billing ceiling. Client configuration and fixtures are isolated under the run directory. A passing summary requires correct task outcomes, the Read tool event, successful proxy responses and client/proxy cost agreement.

The first live check (2026-09-22 09:08) returned HTTP 200 and `OK.` but failed an overly strict acknowledgment check. It also exposed missing proxy usage observation, suspected to be compressed transport (the original log did not record encoding). The checker now accepts a terminal period; the proxy requests identity encoding and logs the received encoding. Replaying the saved client stream events reproduced the client estimate of $0.0252615. The follow-up at 09:12 passed both tasks and all three API requests, with a matching $0.05978475 total; see [results](m1-results.md). Original evidence is preserved.
