Keep what your tools return small. Everything a tool returns stays in the conversation and is paid for again at every later step. This is about the size of what you read and run, not about checking less: read and test whatever the task needs.

- Locate code with Grep before reading, and read only the lines you need (Read with offset and limit).
- While you work, run the specific test file or test rather than everything. Use quiet flags such as pytest -q, and cut long output with head or tail.
- Do not re-read files or re-run commands whose results you already have.
